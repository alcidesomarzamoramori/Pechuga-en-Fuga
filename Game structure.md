# Construcción en Godot
- Godot 4.x
- Juego 2D
- Resolución base: 480 × 854 (vertical)
- Personaje que cae por gravedad.
- ESPACIO, clic o toque para saltar.
- Obstáculos que se desplazan hacia la izquierda.
- Generación automática de obstáculos.
- Detección de colisiones.
- Sistema de puntuación.
- Game Over.
- Botón para reiniciar.
- Récord guardado localmente.
